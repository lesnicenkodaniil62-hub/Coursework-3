# Проект: Анализ воздушного пространства

## Описание

Система мониторинга воздушного пространства в реальном времени на основе API **OpenSky Network** и **Nominatim (OpenStreetMap)** с хранением данных в **PostgreSQL**.

Проект собирает телеметрию полётов, автоматически обновляет данные каждый час, выполняет аналитические запросы (количество самолётов по странам, средняя скорость, поиск по позывному и т.д.) и сохраняет всё в реляционную БД.

**Ключевые особенности:**
-  Геокодирование стран через Nominatim (координаты + bounding box)
-  Получение данных о самолётах в реальном времени через OpenSky
-  Хранение и анализ данных в PostgreSQL
-  Автоматическое обновление данных каждый час (`schedule`)
-  Валидация и автокоррекция данных (отрицательные скорости/высоты, некорректные координаты)
-  Аналитические запросы (средняя скорость, поиск по ключевому слову, статистика по странам)
-  Логирование в файл (`logs/app.log`)
-  Полное тестовое покрытие через `pytest`
-  Строгая типизация (`mypy`) и форматирование кода (`black`, `isort`, `flake8`)

## Использование:

Запуск приложения:
python main.py
При старте приложение:
1. Создаёт таблицы countries и airplanes в PostgreSQL
2. Загружает данные о странах и самолётах
3. Выводит статистику в консоль
4. Запускает планировщик для автоматического обновления каждый час
Для остановки нажмите Ctrl+C.

Пример вывода
